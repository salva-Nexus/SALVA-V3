# Salva V3

Salva V3 is a decentralized P2P liquidity pool built on Base L2, enabling seamless on-chain exchange between NGNs (Nigerian Naira stablecoin) and USD-pegged tokens (USDC, USDT).

Unlike V2 which relied on a centralized OTC desk and backend relay, V3 brings the exchange fully on-chain — users swap directly against a pool at oracle-determined rates, with no intermediary, no Safe multisig relay, and no off-chain minting.

The pool is permissionlessly pausable by the deployer for emergency situations, and exchange rates are managed on-chain via a built-in oracle, making the system transparent and auditable at every step.

---

> 🚧 V3 is currently in active development and has not been audited.
